# PlacementPrep AI 🚀

AI-powered placement preparation platform that helps students practice interviews, analyze resumes, generate roadmaps, and prepare smarter for placements.

## ✨ Features

- 🤖 AI Mock Interview with real-time evaluation
- 🧠 Structured feedback with score, strengths, weaknesses, and tips
- 📊 Dashboard for progress tracking
- 📄 Resume Analyzer with PDF upload support
- 🗺️ AI Roadmap Generator
- 🤖 AI Mentor Chat
- 📄 Cover Letter Generator
- 🔐 Clerk Authentication with protected routes
- 🎤 Voice input support
- 📱 Responsive UI

## 🛠 Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Zustand
- Groq API
- Clerk Auth
- Recharts
- PDF.js
